# Security

Please report a vulnerability privately, not in a public issue:

- email security@keenable.ai, or
- use GitHub's [private vulnerability reporting](https://github.com/keenableai/keenable-cli/security/advisories/new).

Include the CLI version (`keenable --version`), your OS, and the steps to
reproduce. We fix security issues in the latest release; update with
`keenable update` or `brew upgrade keenable-cli`.
